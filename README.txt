WPNfinite Theme
================

This zip includes a working MVP theme based on the WPNfinite project outline.

Included
- Standard WordPress theme structure
- Elementor-friendly full width and canvas templates
- Gutenberg-ready theme.json design tokens
- Reusable CSS architecture
- Starter front page
- Block patterns for hero, pricing, FAQ, content grid, and CTA

Install
1. Upload the zip in Appearance > Themes > Add New > Upload Theme
2. Activate WPNfinite
3. Assign a Primary Menu and Footer Menu
4. Optionally set a static front page
5. Import your Elementor templates separately if needed
